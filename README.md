# Burp Suite HTTP Interception Lab

## Overview

Performed HTTP traffic interception and request analysis in a
controlled cybersecurity lab using Burp Suite, Firefox, and
Metasploitable 2.

The objective of this lab was to understand how HTTP requests
and responses travel between a web browser and a web server,
and to learn how Burp Suite can be used to intercept and inspect
web traffic.

## Lab Environment

- Kali Linux
- Burp Suite
- Firefox

- VirtualBox

## Objectives

- Configure Firefox to work with Burp Suite.
- Configure Burp Suite Proxy.
- Intercept HTTP requests.
- Inspect HTTP request headers and parameters.
- Forward intercepted requests to the web server.
- Analyze HTTP responses.
- Understand the relationship between a browser, proxy,
  and web server.

## Tools Used

### Burp Suite

Used as an HTTP/HTTPS interception proxy to capture and
inspect web traffic between Firefox and the target web server.

### Firefox

Used as the client/browser to generate HTTP requests.

### Metasploitable 2

Used as an intentionally vulnerable web application target
in a controlled lab environment.

## HTTP Request Interception

Burp Suite Proxy was configured to intercept HTTP requests
generated by Firefox.

Example workflow:

Firefox → Burp Suite → Metasploitable 2

When a request was generated, Burp Suite intercepted the
request before forwarding it to the target server.

## Request Analysis

The intercepted HTTP request was examined for:

- HTTP method
- Request URL
- HTTP version
- Host header
- User-Agent
- Other HTTP headers
- Request parameters

Example:

GET / HTTP/1.1
Host: 192.168.56.102

## HTTP Response Analysis

The response returned by the Metasploitable 2 web server
was also examined.

Important response information included:

- HTTP status code
- HTTP version
- Response headers
- Response content

For example:

HTTP/1.1 200 OK

A 200 OK response indicates that the server successfully
processed the request and returned the requested resource.

## Observations

During the lab, HTTP requests generated by Firefox were
successfully intercepted using Burp Suite.

The requests could be inspected before being forwarded to
the Metasploitable 2 web server.

This demonstrated how an interception proxy can be used to
analyze communication between a web client and server.

## Security Relevance

HTTP interception is an important skill in web application
security testing.

Understanding HTTP requests and responses helps security
analysts and penetration testers identify issues related to:

- Authentication
- Session management
- Input handling
- Request parameters
- Security headers
- Web application behavior
